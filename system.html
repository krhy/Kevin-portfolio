Description

How the Automation Framework works.

The three agents remain outside the execution ecosystem and connect only through the shared knowledge base.

Knowledgebase Harness

Keep knowledge current

When new application documents appear, the agent ingests, structures and appends them to the Git-backed knowledge base.

  • Jira tickets and attachments
  • Requirements, Swagger and schemas
  • Metadata and application code
Test Writer Agent

Expand automation

Uses the requirements document, code coverage report and retrieved knowledge to create or improve automation scripts.

  • Requirement-led Java tests
  • Coverage gaps prioritized
  • Uses framework conventions
Test Failure Triage

Explain failures

Examines execution evidence to distinguish application defects from data, environment and test-script issues.

  • Application bug or defect
  • Data or environment issue
  • Test-script issue
