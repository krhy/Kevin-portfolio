Overview

What I Do

I'm a Software Engineer – Sr. Consultant/SDET at Visa Worldwide. I built VTAF, a unified test automation framework covering UI, REST, and SOAP layers, for a global payments dispute resolution platform running on Java/JVM and Python microservices, and integrated it into our CI/CD pipelines using Jenkins and GitHub Actions.

Over the last year, I've been bringing agentic AI into the QA workflow: connecting AI agents via MCP to automatically pull logs and cross-reference source code, and building agent skills (Markdown-based instruction files that double as a knowledge base) so the system can tell on its own whether a failed test is a real bug, a bad script, bad data, or an environment issue.

I've also worked as part of our Security team on SAST (Checkmarx) and SCA (Sonatype) findings, fixing flagged issues and building automation to test for them going forward.

I'm ISTQB Certified at the Advanced Level across both streams, with experience running teams as a certified Scrum Master.
